01 — Проекты

Мессенджер со звонками и сквозным шифрованием

Rust · Flutter · flutter_rust_bridge · WebRTC · Kotlin · Android SDK/NDK · ADB · Ansible

Звонки для узкого круга без сторонних сервисов → свой протокол на стандартной криптографии (Ed25519, X25519, XChaCha20-Poly1305), медиа P2P, сервер не видит содержимого; Kotlin-сервисы звонков и уведомлений под Android 15, отладка через ADB по Wi-Fi → APK и установщик Windows одним скриптом, сервер разворачивается Ansible, 145 коммитов.

Игровой движок ofeliaengine

Rust · Vulkan 1.3 · Slang · Luau · Fluent · ICU4X · Tracy

Движок под Windows: рендер, физика, звук, сеть, скрипты → 45 модулей, 120 архитектурных решений (ADR), 1250+ коммитов. Модуль локализации: строки по ключам в Fluent, русские формы множественного числа и падежи (ICU4X), откат на базовый язык, автоматическая проверка полноты перевода.

Локальный ИИ на своём железе

llama.cpp · Open WebUI · ComfyUI · Python · MCP · Docker (WSL) · SQLite FTS5

Gemma 4 26B с контекстом 256K на видеокарте 16 ГБ, генерация изображений (FLUX) и видео (Wan, LTX) → свои инструменты для модели: веб-поиск, офлайн-базы законов и медрекомендаций, PubMed, автоматическая сверка ответа с источниками.

Реверс-инжиниринг сайтов и закрытых API

DevTools · HTTP/JSON · Python · SQLite · разбор форматов (MHTML, XLSX, XML)

Сначала понять, где лежат данные и как их достать, потом — как добавить своё → разбирал и парсил Домклик, Спортмастер, О’КЕЙ, API образовательной платформы Сбера (Школа 21); нашёл недокументированные API сайта клинрекомендаций Минздрава и «Законодательства России», скрытую выгрузку Госреестра лекарств → из них — локальные базы с поиском: 93 рекомендации, 17 кодексов, 15,5 тыс. названий лекарств.
